# Project Name

The project consists of a set of sections that can be navigated using the navigation bar.
Designed using scss language.
The intersection observer feature was used in this project, along with a set of features such as transitions, animations, and form submission 

## Features

- The intersection observer
- form submission
- responsive design 
- smooth navigation bar 

## Requirements

Before you begin, ensure you have met the following requirements:

- [Install Node.js](https://nodejs.org/)
- run sass-dev
